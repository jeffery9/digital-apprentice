# 第1章 AI Agent 概述

## 1.1 什么是 AI Agent

AI Agent（人工智能体）是指能够**感知环境**、**自主决策**并**采取行动**以完成目标的软件系统。与传统的"一问一答"式聊天机器人不同，Agent 具备以下核心特征：

- **自主性（Autonomy）**：无需人类逐步指令即可规划并执行任务。
- **感知能力（Perception）**：能读取文本、图像、网页、数据库等多模态信息。
- **行动能力（Action）**：通过调用工具（Tool Use）与外部世界交互。
- **记忆与学习（Memory）**：保留短期上下文与长期经验，持续改进策略。

> 一句话总结：**LLM 是大脑，工具是手脚，记忆是经验，循环是意志。**

## 1.2 Agent 与 Chatbot 的区别

| 维度 | 传统 Chatbot | AI Agent |
| --- | --- | --- |
| 交互模式 | 单轮问答 | 多轮目标驱动 |
| 决策方式 | 模板/检索匹配 | LLM 推理 + 规划 |
| 外部能力 | 无或有限 | 工具调用、代码执行、联网 |
| 状态管理 | 无持久状态 | 短期+长期记忆 |
| 失败处理 | 直接回复不知道 | 反思、重试、换策略 |

## 1.3 Agent 的典型应用场景

1. **编程助手**：自动补全、重构、修复缺陷、编写测试。
2. **深度研究**：多轮检索文献、交叉验证、生成综述报告。
3. **客服与运营**：工单分类、退款流程自动化、多渠道协同。
4. **数据分析**：自然语言转 SQL、自动生成图表与洞察。
5. **办公自动化**：会议纪要、文档组装、邮件流转。

## 1.4 本章小结

本章给出了 AI Agent 的定义与四大特征，并通过对比表说明了它与传统 Chatbot 的本质差异：**目标驱动 + 工具使用 + 循环执行**。后续章节将围绕这一主线，逐层拆解 Agent 的技术栈。

# 第7章 总结与展望

## 7.1 全书要点回顾

| 章节 | 关键结论 |
| --- | --- |
| 第1章 | Agent = 感知 + 决策 + 行动 + 记忆的闭环系统 |
| 第2章 | 五层架构：模型/记忆/规划/工具/编排，工程框架约束模型不确定性 |
| 第3章 | ReAct 是心跳；轨迹、停止条件与兜底决定成败 |
| 第4章 | 上下文是最稀缺资源；RAG 做好切块、混检与引用溯源 |

| 第6章 | 多 Agent 按需拆分；三层评估 + 安全护栏走向产品化 |

## 7.2 落地路线图

1. **选型**：从高频、低风险、可验证的任务切入（如文档问答、报表生成）。
2. **搭骨架**：先实现带轨迹记录的 ReAct 单循环，再逐步加记忆和并行。
3. **建评估**：黄金测试集先行，任何 Prompt/模型改动必须过回归。
4. **上护栏**：预算熔断、权限分级、人工审批三道防线缺一不可。
5. **持续运营**：线上失败案例回流测试集，形成数据飞轮。

## 7.3 趋势展望

- **长任务化**：从分钟级问答走向小时级自主工作，考验记忆与自我纠错。
- **计算机使用（Computer Use）**：以 GUI 为接口操作真实软件，通用性更强。
- **标准化协议**：MCP 等协议让工具生态像 App Store 一样可组合。
- **评测驱动研发**：Agent Benchmark 成为与模型榜单同等重要的基础设施。
- **人机协同深化**：HITL 不是能力不足的妥协，而是信任与责任的制度设计。

## 7.4 结语

Agent 的竞争最终不在"模型有多聪明"，而在"系统有多可靠"。把不确定的智能装进确定的工程外壳，是这个时代软件工程师最重要的新功课。

# 资产体系规范（表格・插画・表单）

> 本文件供 long-form-book-writing 技能阶段 4 使用。原则：资产与正文并列管理，凡资产必有编号、母本、prompt 登记与验收清单。

## 1. 表格体系

### 1.1 两类表格，两套编号

| 类别 | 编号 | 用途 | 位置 |
|---|---|---|---|
| 随文表 | 表 x-y（章-序） | 解释、对比、索引，服务阅读 | 章内正文 |
| 可复印表单 | T-01…T-nn（全书连续） | 读者动手时填写的记录单/单据/清单 | 章内嵌入＋母本文件 |

编号在策划案阶段预留，写作中只许按预留填，不许临场重排（重排＝全书交叉引用返工）。

### 1.2 表单四件套（缺一不可）

每张 T-xx 表单必须包含：

1. **编号标题行**：统一格式 `【表单 T-0x｜表单名】`；
2. **表头字段行**：每列一个明确字段名（日期/操作/预期/实际/结论……）；
3. **示例行**：第一行填一个真实感示例，读者照葫芦画瓢；
4. **脚注**：一行说明何时用、交给谁、保存多久。

勾选框用统一符号（如 `☐`），生成后 grep 检查缺符；markdown 表格内**空单元格也要写占位**，防止管道表塌行。

### 1.3 母本与同步纪律

- **《表格成品集.md》＝排版母本**：T-xx 全内容＋随文表索引，是唯一供设计师排版的权威版本；
- 章内嵌入的是**阅读版**（完整四件套，与母本内容一致）；
- 同步纪律一句话写进母本文件头与进度文件：**"改一处须照改另一处"**；
- 历史教训：曾出现"章内只放简版＋指针"的做法，读者到手发现表单不完整——**阅读版必须完整嵌入**，指针只能作为补充不能替代；
- 审计项：登记表有而正文无（漏嵌）、正文有而登记无（漏登）双向都要查。

### 1.4 表格排版 Prompt 文件

供设计师/排版 LLM 使用，四层结构：

1. **全局排版 prompt**：一段可逐字粘贴的总规范（字体字号倾向、边框、表头底纹、跨页重复表头、caption 位置）；
2. **分族 prompt**：按表族追加差异化规则。实测四族分法：
   - 族 A＝随文解释表（轻量，无边框或细线）；
   - 族 B＝记录表单（格大、留填写空间、勾选框）；
   - 族 C＝单据模板（编号/签字/验收栏，正式感）；
   - 族 D＝检查清单（勾选列突出）；
3. **逐表卡**：每张 T-xx 一张卡（用途、所在章、字段说明、排版注意点）；
4. **验收清单**：每张表交付时核对的 5–8 条（编号一致、字段齐全、示例行在、脚注在、勾选符不缺、宽度适配版心）。

## 2. 插画体系

### 2.1 先定调，再量产

1. **风格样张**：正式生产前先出 3–4 张不同方向样张，与用户选定一种；样张文件保留（命名 `风格样张_*`），作为后续所有 prompt 的对照基准；
2. **全局风格前缀**：一段固定的风格描述文字，每条 prompt 开头逐字粘贴；
3. **全局负面提示**：固定追加的排除项（文字、水印、照片感、多余肢体等）；
4. **统一资产库（角色与比喻物）**：反复出现的角色与比喻物逐个写下**固定形象设定**，所有 prompt 引用同一设定——**禁止各画各的**。详见 §2.1.1。

### 2.1.1 角色资产库登记表（来自《数字见习生》实践）

角色与比喻物必须在资产库中登记，全书统一形象。示例：

| 资产 | 设定 | 首次定义 |
|---|---|---|
| **数字见习生**（主角） | 圆角方形小机器人，大圆屏幕眼，左臂"见习生"袖标，抱笔记本与铅笔；表情组：勤快/困惑/干活/翻车 | 样张 1 |
| **大脑** | 悬浮的发光粉色大脑，总是关在无窗小黑屋里；门缝是唯一通道 | 样张 1 |
| **任务简报包** | 牛皮纸六插袋文件封套（后续可升级为十三层公文包） | 样张 2 |
| **办公桌** | 木纹小桌＋文件 tray；"桌面大小"即上下文窗口 | 图 8-3 |
| **轨道/流水线** | 传送带＋信号灯＋红色闸口＋路障＋警示牌 | 图 6-1 |

**为什么需要资产库**：
- 图像模型每次生成都是独立的，没有"记忆"，必须用文字锁定形象
- 同一角色在不同章节出场时，如果 prompt 描述不一致，会导致形象漂移
- 资产库表格是**全书唯一权威**，所有 prompt 必须引用同一设定
- 实测教训：曾出现"主角在图 1-1 是圆角、在图 5-1 变直角"的问题，读者会困惑

### 2.2 画面无文字铁律

- 生成图内**不出现任何文字**（含中文标注、字母标签）；图像模型写中文几乎必错，且错字无法后期修；
- 需要标注的图：prompt 只画"标注位"（留白/箭头/空框），**标注位说明以文字登记在交付清单**，由设计师后期加字；
- 正文引用无字底稿时，标注说明可用引用块暂附在图后，注明"定稿前移除"，组装脚本按草稿注释剥离。

### 2.3 命名与登记

- 文件名编码用途与编号：如 `P1_图3-2_资料室.png`（批次/篇章前缀＋图号＋内容短语）；同一资产系列共用前缀；
- **《插画交付清单.md》**结构：
  1. 全局视觉规范（风格前缀、负面提示、资产库、规格）；
  2. 逐图交付卡（按章排序；每卡＝图号、位置、画面描述、完整 prompt、标注位说明）；
  3. 批量模板（思维导图、收藏卡等系列件的模板 prompt＋逐张内容槽）；
  4. 书籍级插画（封面多方案、篇扉页、拉页——各自登记候选状态与推荐项）；
  5. 交付批次与验收；
  6. **审计记录节**：历次断链修复、重绘、精修全部记录在案。
- **每张已生成图的完整 prompt 必须登记**（含批量模板件的逐张展开版）——保证任何一张都能重绘/修订，这是插画体系的"可复现性"底线。

### 2.4 批量件用模板生产

- 系列图（每章思维导图、每构件收藏卡）先做一张标杆，抽成**模板 prompt**（固定构图/风格＋内容槽），逐张只替换内容槽；
- 模板件同时保留"通用模板"与"逐张完整 prompt"两份：前者供理解，后者供直接重跑；
- 生成后逐张 read_file 目检：构图是否符模板、资产形象是否一致、有无意外文字。

### 2.5 封面与书籍级件

- 封面出 **2–3 个方案**（不同构图方向），各登记候选状态与推荐理由，选择权留给用户/编辑；
- 封面图预留文字区（书名/作者名后期加），prompt 中明确"上方/下方留空"；
- 篇扉页、拉页（大场景总览图）单独立项，不混入正文插画批次；
- 源图规格统一（如 2048×2048 PNG），**压缩只发生在构建层**（见 pipeline.md），源图永不动。

### 2.6 两段式工作流（AI 出底稿 + 设计师加字）

**为什么需要两段式**：
- 当前图像模型渲染中文的出错率高（错字、粘连、乱码）
- 书籍插图的标注需要与正文术语严格一致
- 直接采用模型成图有版权与一致性风险

**工作流**：
1. **第一段：AI/插画师出无字底稿**
   - prompt 只画画面，不画文字
   - 标注位用留白/箭头/空框表示
   - 标注位说明以文字登记在交付清单
   
2. **第二段：设计师在矢量软件中加中文标注**
   - 使用 Illustrator/Figma 等矢量软件
   - 按交付清单的标注位说明加字
   - 字体、字号、颜色按全书统一规范

**实测效果**（《数字见习生》）：
- 全书 46 幅插画，采用两段式工作流
- AI 出底稿效率：每天可产 8-12 张
- 设计师加字效率：每张 15-30 分钟
- 总成本：比纯手绘降低 60%，比纯 AI 生成质量提升 80%

### 2.7 封面多方案与候选状态

**封面生产流程**：
1. 出 **2-3 个方案**（不同构图方向），各登记完整 prompt
2. 每个方案登记：
   - 文件名（如 `封面_方案A_书上接文件.png`）
   - 候选状态（候选/推荐/淘汰）
   - 推荐理由（一句话）
3. 选择权留给用户/编辑
4. 封面图预留文字区（书名/作者名后期加）

**《数字见习生》实践**：
- 概念图＋方案 A/B/C 共 4 件在册
- 推荐序：A（与资产库形象最一致）→ B（人机协作叙事）→ C（极简象征）
- 三方案均为 2048×2048 方幅，主视觉居中偏上、上下横带已留字区
- 改 16 开竖幅（2:3）时由设计师上下裁切或延展，不改主体构图

### 2.8 交付批次与验收

**批次划分**（按依赖关系）：
| 批次 | 内容 | 说明 |
|---|---|---|
| **P0（先行定调）** | 角色资产设定页＋关键决策图 | 全书复用资产与关键图，风格以此为准 |
| **P1（概念插画）** | 比喻类主视觉 | 依赖 P0 资产库 |
| **P2（流程与模板）** | 流程图＋模板图＋思维导图＋构件卡 | 可用模板批量产出 |
| **P3（表格排版）** | 表格/单据 | 排版设计，非插画 |

**逐图验收清单**（6 条）：
1. 与正文该章"配图说明"逐项相符
2. 资产库形象一致（角色不走形）
3. 标注位齐全且术语与附录一致
4. 单色降级版可读（灰度打印不糊）
5. 双色套印不越界（如适用）
6. 无画面内错字（文字均为后期矢量添加）

## 3. 模板件（读者可复印使用的件）

手册/单据/蓝图/清单类模板件：

- 正文中以**引用块或表格**呈现，自然语言，不破坏书的阅读契约（如零代码承诺）；
- 每件有编号（T-xx 或图 x-y），在附录汇总成套（"模板件总目录"）；
- 若设计师不用现底稿重排，交付清单注明"可按样张填装"并指向样张。

## 4. 资产生产节奏（实测有效）

1. 正文写到某章时**只登记**该章图表需求（编号＋画面描述），不立即生产；
2. 正文全部完成后，**分批集中生产**（如每批 8–12 张），批内风格一致性最好控制；
3. 每批生产完立即：目检→登记 prompt→插入正文引用→更新交付清单与进度文件；
4. 全书图表齐后跑一次**资产总审计**（见 audit-and-handoff.md §2），再进组装。

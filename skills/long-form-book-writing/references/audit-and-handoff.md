# 审计与交付

> 本文件供 long-form-book-writing 技能阶段 6–7 使用。口号：**凡交付必审计；AI 侧零未销项，剩余工作全部是外部依赖。**

## 1. 四类自动终检（跑在合并版 md 上）

每次改动源稿并重跑组装脚本后执行；也可写成独立审计脚本一次跑完。

### ① 断链检查（双向）
- **正向**：合并版中每处 `![...](路径)` 的文件必须存在；每个交叉引用（"见 §x.y / 附录 B 第 n 条 / 图 x-y / 表 x-y / T-xx"）的目标必须存在；
- **反向**：登记表（插画交付清单、表格成品集）中登记的每一件，正文必须实际引用——**"登记有、正文无"同样是断链**（实测曾发现 4 张表体只在登记表里）；
- **前缀混淆重点查**：图片文件名带批次/篇章前缀（P0_/P1_/P2_…）时，正文误引相邻前缀是高发错误（实测 3 处），grep 时对每个编号列出全部前缀变体核对；
- 图号/表号/T 编号**连续无跳号、无重号**。

### ② 编号完整性
- 每个表题行 `【表 x-y｜…】` 下方必须跟真实表体（管道表），有题无体＝事故；
- 每张 T-xx 表单四件套齐全：编号标题、表头字段行、示例行、脚注；
- 勾选框符号不缺（grep `☐` 计数对表）；
- 栏目符号计数合理（每章"比喻的边界"≥1 之类的全书不变量，可写成断言）。

### ③ 引号与金句
- 合并版 grep ASCII 直引号 `"` `'` 残留＝0（规范化兜底后仍出现说明源稿有奇形结构）；
- **金句锚点逐句核对**：进度文件 §四照录的每句金句，grep 全书出现处，措辞必须逐字一致（审校、封面文案、目录简介最容易改写金句）；
- 术语一致性抽查：术语表（附录 A）每条术语在正文的写法与术语表一致（抽查高频 20 条）。

### ④ 表格构造
- docx 侧：正文段落中残留 `|` 字符＝0（管道表未被识别的信号）；
- docx 表格总数 ≥ 预期（源稿管道表计数）；
- markdown 侧：所有管道表前后有空行（脚本已保证，抽查确认）。

## 2. 资产总审计（图表齐后、组装前跑一次）

- 插画交付清单逐条 vs 图片目录逐文件：数量、命名、登记 prompt 三对齐；
- 每张图 read_file 目检一遍：资产形象一致、无意外文字、构图符模板；
- 表格成品集 vs 章内阅读版：逐张对照四件套与字段行（同步纪律的验收）；
- 审计结果（发现几处、修复几处）写入交付清单"审计记录"节——**审计本身也要留痕**。

## 3. 构建体检（docx 生成后）

用 python-docx 快速读数，与预期对表：

| 指标 | 预期来源 |
|---|---|
| H1 数量 | 篇扉页＋章＋前后记＋附录总数 |
| 静态目录条目数 | H1＋H2 计数 |
| 内嵌图片数 | 正文引用数＋篇扉页 |
| 表格数 | 源稿管道表计数 |
| 文件体积 | 压缩开启时应在个位数 MB 量级 |
| 残留 `|` 段落 | ＝0 |

## 4. 人工审校清单（AI 备料，人来审）

四轮审校，每轮 AI 的职责是**准备材料包**而不是代审：

1. **技术准确性**（领域工程师）：备料＝比喻对照表＋"比喻的边界"框汇编＋源材料映射表；重点审比喻失真、产品能力描述、版本号；
2. **导流一致性**（编辑/AI 辅助）：备料＝全部深化路标、原理速览、现象索引条目的导出清单；逐条核对双向可达；
3. **读者实测**（3–5 名目标读者）：只靠正文（不给作者答疑）完成全部动手实验＋毕业项目；备料＝实验速查表＋表单套装＋记录台账；观察卡点即修订线索；
4. **文字校对**（编辑）：备料＝金句锚点清单＋术语表＋栏目符号说明。

审校反馈回来后走 v0.9 修订批次：逐条登记反馈→修订→重跑组装→四类终检→版本历史记一行。

## 5. 交付分工表（进度文件 §五的模板）

| 事项 | 依赖 | 说明 |
|---|---|---|
| 占位事实填充 | **作者** | 前言致谢与案例来源；后记方括号（AI 参与范围、核验方式、署名日期）；时效日期与产品版本号 |
| 四轮审校 | 工程师＋目标读者＋编辑 | 见 §4 |
| 设计师工序 | 插画师/排版 | 无字底稿加文字标注（标注位见交付清单）；表格按排版 Prompt 出版式；封面多方案选定后加文字带、裁竖幅；篇扉页横带；模板件重排（可选） |
| 出版配套 | 编辑 | 目录页、版权页（含 AI 参与披露）、封底文案（可复用策划案电梯陈述缩写）、封面文字区 |

**交付物清单**（AI 侧产出全集）：
- 分章源稿（含前后记、附录）＋进度文件（终态版）；
- 策划案与详细大纲；
- 资产三件：表格成品集、表格排版 Prompt、插画交付清单（含全部 prompt 与审计记录）；
- 图片库（源图 PNG＋风格样张）；
- 组装脚本＋输出/（合并版 md＋docx＋样式模板 reference.docx）。

## 6. 终态声明

项目收尾时，进度文件标题改为"终态版"，满足三条：

1. §五剩余工作**全部**为外部依赖（作者/审校/设计师/编辑），无 AI 侧待办；
2. 四类终检＋资产总审计＋构建体检全绿，审计记录在案；
3. 版本历史完整可追溯：从 v0.1 到终态，每行都能回答"这批改了什么、为什么"。

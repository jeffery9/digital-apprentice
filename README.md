# 《数字见习生》书稿项目

面向**无编程经验读者**的 AI 智能体（Agent）入门教材——副题：不懂编程，也能理解和使用 AI Agent。

采用三段教学法：**先入门 → 再动手 → 然后深入**，最后守住边界。全书零代码，共 15 章 + 前言后记 + 附录 A–G，约 21 万字符，当前处于**终稿维护状态**（版本以 `book/书稿/00_书稿进度.md` 为准，现为 v0.8l）。

本仓库同时是"吃自己的狗食"的实践现场：本书教读者组装数字见习生，本书自己的书稿维护也用同一套方法（见 `book/见习生工位/`）。

## 快速开始

### 环境依赖

- Python 3
- `pypandoc-binary`（自带 pandoc）、`python-docx`、`pillow`

### 组装书稿

```bash
cd book
python3 assemble_book.py                # 默认：剥离草稿注释、压缩图片、中文弯引号、静态目录
python3 assemble_book.py --keep-notes   # 保留草稿注释行
python3 assemble_book.py --no-toc       # 不生成目录页
python3 assemble_book.py --outdir DIR   # 自定义输出目录（默认 book/输出/）
```

产物为 `book/输出/《数字见习生》全书稿_合并版.md` 与同名 `.docx`。脚本对源文件**只读**，重跑即全量再生成（幂等）。

### 出版前终检

```bash
cd book
python3 prepub_check.py
```

执行四类终检（断链 / 编号 / 引号 / 表格）+ 出版就绪核对，报告落盘至 `book/见习生工位/台账/`。

## 维护纪律（改稿必读）

1. **先读权威文件**：动 `书稿/` 前先读 `书稿/00_书稿进度.md` §四写作约定与 §五剩余工作；
2. **一次只改一处**：多处修改先列清单请作者确认顺序；
3. **表单双向同步**：改动任何 T-xx 表单，须照改《表格成品集》母本与章内阅读版两处；
4. **改稿必走闭环**：改完依次执行「组装书稿」→「四类终检」，终检不全绿不得报告完成；
5. **占位事实宁缺毋假**：人名、日期、版本号、网址一律用【方括号】留空并登记，绝不编造；
6. **十句金句锚点措辞不可改动**；不改 `书稿/插画/` 源图；构建过程不写源文件。

完整规矩见 `book/QWEN.md`（员工手册）与 `skills/long-form-book-writing/SKILL.md`（长篇写作全流程方法论）。

## 项目角色

- **作者**：一位面向无编程经验大学生写作的老师，是唯一验收人；
- **数字见习生（维护秘书）**：由终端智能体（Qwen Code 一类）加载 `book/QWEN.md` 担任，负责按修订意见改稿、维护登记表一致性、执行组装与终检、起草版本历史条目。

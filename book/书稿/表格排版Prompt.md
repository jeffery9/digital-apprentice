# 《数字见习生》表格排版 Prompt 与规范

> 对象：P3 批次 22 张表格/单据（清单见《插画交付清单》§五）＋本书全部随文表
> 配套成品：`表格成品集.md`（12 张独立表单的完整内容已备好，可直接排版）
> 使用方式：§一全局 prompt 逐字固定；§三分表 prompt 只换"内容段"

---

## 一、全局排版 Prompt（粘贴给 LLM / 排版工具时逐字使用）

> 你是教育类图书的版式设计师。把提供的 markdown 表格转换为**书稿排版规格＋打印就绪 HTML**，遵守以下规范，不得增删表格内容：
> 1. 开本 16 开（170×240mm）双色印刷：主色深蓝（≈PANTONE 534C）、辅色暖橙（≈PANTONE 163C），其余灰阶。
> 2. 表题置于表上：`表 x-x　表名`，黑体 10.5pt，深蓝；表序与表名间全角空格。
> 3. 表头：深蓝底、反白字、黑体 9.5pt；或三线表式（顶线 1.5pt、表头线 0.75pt、底线 1.5pt，深蓝）。全书二选一并统一，默认**三线表式**。
> 4. 表身：宋体 9pt，行距 1.4；隔行浅灰（5% 黑）底纹；单元格内边距 2mm；左对齐，数字列右对齐。
> 5. 跨页表：重复表头，续页右上角加"（续）"，顶线改 0.75pt。
> 6. **可复印表单类**（记录单/清单/蓝图）：米色 8% 底纹、行高 ≥8mm 手写区、左侧撕孔边（六个圆孔）＋剪刀图标、表题旁加"可复印"圆角章；示例行用浅灰斜体预印，空行以细虚线格呈现。
> 7. 表注/填写说明置于表下：8pt 灰，前加"注："或"填写说明："。
> 8. 强调规则：红线类文字（"绝不""禁止"）暖橙加粗；判否列用 ☐ 勾选框；"我没说过"等特殊栏表头预印暖橙。
> 9. 输出两态：①排版规格说明（给纸质书设计师）；②单文件 HTML＋内嵌 CSS（给电子预览，不依赖外部字体与脚本）。
> 10. 禁止：彩色渐变、阴影立体、外部图片、javascript。

**负面清单**：不改动原文措辞；不合并/拆分单元格内容；不为对齐而删列；示例行不得冒充空行。

**族 B｜可复印记录单**（T-01~T-06、T-08、T-09、T-11，即图 1-6/2-3/2-4/3-4/4-3/5-2/6-3/11-5 与附录 F 台账表）

**族 D｜清单卡片**（图 3-3 核验清单的文字版、图 11-5 体检清单的卡片版）

## 四、验收清单（每张表交付时核对）

① 表题序号与章节图清单一致；② 列名与正文引用处措辞一致（如"遗留问题"不得排成"备注"）；③ 示例行与空行 visually 可区分；④ 复印测试：黑白打印后底纹不糊、勾选框可写；⑤ 红线文字暖橙在灰度下仍加粗可辨；⑥ HTML 预览无外部依赖。

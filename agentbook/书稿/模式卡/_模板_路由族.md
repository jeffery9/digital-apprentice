# 模式卡模板 · 路由族（第 4 章模型编排与路由 / 第 12 章协议）

> 用法：复制下面的空表到章稿中，替换 `〈…〉`。九字段一个都不能删。

【模式卡：〈中文名〉（〈english name〉）】

| 字段 | 内容 |
| --- | --- |
| **名称** | 〈中文名〉（〈english name〉） |
| **意图** | 〈一句话，≤40 字〉 |
| **问题** | 〈什么困境下出现〉**＋本族必答：这是工作流路由（编排层选分支）还是模型路由（接入层选模型）？首次共现处必须辨析（附录 B 立条）** |
| **结构** | 〈组成部件与关系。路由类模式必须写清：判据从哪来、决策在哪一层做、决策结果怎么记进遥测〉 |
| **适用场景** | 〈可判定的具体条件〉**＋本族必答：数据门槛是多少？（没有生产日志就别上学习式路由）** |
| **不适用场景** | 〈什么条件下用它是错的〉 |
| **风险与代价** | **本族必答三项：①成本口径——是否计入重试与级联双跑？②路由自身的延迟税与故障点；③目标混淆风险（韧性／成本／质量三个目标各自的度量是什么，混用会怎样）** |
| **关联模式** | 〈同族／跨族关联，逐个标章号〉 |
| **出处与实例** | 〈论文／规范／开源系统，带年份〉；〈智航案例情节〉；**若提及具体产品，该句必须带【时效锚点｜截至 YYYY-MM】** |

## 本族填写注意

1. **不写单价、不写排名、不做推荐。** 产品名只在时效锚点区块内作为格局说明出现（QWEN.md §七）。
2. **成本口径必须显式。** 路由类模式最常见的自欺是"省了钱"却没算级联双跑与重试。第 19 章会给完整的单位经济学模型，本族卡在第 7 字段回指即可，不重讲（铁律一）。
3. **agent 场景的特殊性**：一次用户回合＝多次模型调用＝多次路由决策。任何路由卡都要回答"这个决策在哪个调用点上做"，否则等于只优化了第一跳。
4. **协议族（第 12 章）额外必答**：防腐层在哪里、版本策略是什么、退出成本多大。

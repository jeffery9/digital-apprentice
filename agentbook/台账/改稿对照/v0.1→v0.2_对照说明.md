## 四、新增第16章「长时程 Agent 与后台任务」的内容构成（10k／11 节／4 张卡／1 个 demo／8 幅图）

| 节 | 内容要点 | 时效层 |
| --- | --- | --- |
| 16.1 | 决策场景：跨三天迁移核查，第四小时服务重启进度全丢＋夜里预算烧穿 | — |
| 16.2 | **时程轴**：秒级对话→分钟级任务→小时级流程→天级后台；四档时程的架构基线对照表（本章最常被复印的一页） | L1 |
| 16.3 | **误差复利**：端到端可靠性 ≈ 单步可靠性^步数（0.9⁵⁰ ≈ **0.52%**，已用 Python 复算核实）；三个对冲方向（缩短链路／提高单步可靠性／插入检查点）；过程级失败约 72.5% 的实证结论 | L1＋L3 锚点 |
| 16.4 | **可续跑分解**：可独立验证、可重放、幂等的单元；粒度判据（重跑成本 vs 检查点开销 vs 上下文占用）；跨天任务里**显式计划重新变成必需品** | L1 |
| 16.5 | **检查点与持久执行**：状态外置、事件溯源重放、Temporal/durable task 范式的本质；**三种恢复语义**（崩溃恢复／断电续跑／跨天恢复）正确性要求不同；幂等性是重放硬前提 | L2＋L3 锚点 |
| 16.6 | **恢复后的上下文重建（rehydration）**：重建什么／用什么重建／**"恢复即测试"**；任务级记忆 vs 跨任务记忆 | L1 |
| 16.7 | **进度可见性**：里程碑事件 vs 心跳 vs 增量产物；**"沉默的 agent"不可接受**（无法区分在干活与卡死）；部分结果交付；HITL 由可选变必需 | L1 |
| 16.8 | **放弃、超时与预算**：三层超时（步骤/任务/预算）；放弃判据（无进展、重复动作、置信度衰减、外部条件失效）；跨天预算累积与熔断；**"失败了也要交出中间成果"** | L1 |
| 16.9 | **后台化与调度**：队列、并发上限、优先级、租户公平；**无人值守时权限必须单独收敛**；触发方式与重入控制 | L2＋L3 锚点 |
| 16.10 | **长时程的可观测与评估**：分段评估＋里程碑门禁＋人工抽检；跨天 span 组织；过程级 vs 结果级归因口径 | L2＋L3 锚点 |
| 16.11 | 反模式七条（塞进一个窗口、无进展检测烧钱、**检查点存了但恢复没演练过**、进度只有日志没有事件契约、无人值守用交互式权限、失败即全丢、用更强模型解决复利问题） | L1 |

模式卡 4 张（"长时程"族）：**可续跑分解／断点续跑（检查点与持久执行）／恢复后上下文重建／进度事件流**；放弃与超时策略并入"预算护栏"共卡（第19章）。
**卡片归属调整**：v0.1 运行时章的"检查点恢复"卡移入第16章并更名"断点续跑"，运行时章改留"持久执行底座"卡——避免同一张卡在两章重复定义。

Demo **D-18**：后台长时程任务——进度事件流＋预算熔断＋**被 kill 后从检查点恢复并重建上下文**；与 D-11 明确分工（D-11 演示**机制**、D-18 演示**治理**）；用**模拟时钟**把"三天"压到几分钟，不得要求读者真的等。

# D-04　最小模型网关：快照钉扎、按调用点路由、熔断与故障转移

对应书中：**第 4 章 4.4、4.6—4.8 节**。约 100 行实现一个可运行的模型网关骨架：
快照钉扎（禁止漂移别名）、调用点级路由表、熔断三态（closed/open/half-open）、
故障转移候选链、合规分区（regulated 只允许本地部署候选）、预算护栏钩子、按路由遥测（JSONL）。

## 一句话

它是 D-03（路由策略对比）与后续多个 demo（第 6 章预算护栏、第 18 章轨迹采样）的复用基座——
书中所有"挂在网关遥测点上"的能力，都在这里。**演示的是形状与决策可追溯性，不是产品级网关。**

## 最低可跑组合

- **离线（推荐）**：`--mock`。零依赖、零网络、零密钥。
- **真实调用**：经 `code/llm.py` 的 MODEL_POOL 接任意 OpenAI 兼容端点（见 D-01 README 的环境变量约定）。
- **密钥处理方式**：只从环境变量读取，代码与本文档不含任何密钥形态（prepub F6 会扫）。

## 怎么跑

```bash
python gateway.py --mock                                  # 基线：5 个调用点 × 若干任务
python gateway.py --mock --failure-rate 0.4               # 观察候选链迁移与熔断打开
python gateway.py --mock --tier regulated                 # 合规分区在路由之前生效
python gateway.py --mock --budget 500                     # 预算耗尽 → budget_exceeded
```

## 观察什么

1. `failure_rate` 提高后模型分布向候选链下游迁移、熔断打开次数上升；而 `judge` 调用点只有一个候选，于是大面积降级——**没有候选链的调用点没有韧性**（4.8）。
2. `tier=regulated` 时候选集只剩本地部署模型，plan/reply/judge 因无合规模型而**显式降级**而非静默出境——分区在路由之前生效，不可能被绕过（4.10）。
3. 遥测 JSONL 里 `cached`、`degraded`、`model` 三个字段足以复原每次决策的理由——这是 4.4 职责⑦的可验证形式。
4. token 计数口径是 mock 估算，与书中 `T(n)` 公式口径不同：只看形状，不要对齐数值（同 D-01 README 的声明）。

## 已知局限

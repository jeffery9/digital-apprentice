## 观察什么（对应 17.5–17.9）
1. 图像经感知管线转写后与用户指令**同通道混流**——trust_level 必须在进管线前打标。
2. 纵深防御各关一类失败模式：围栏关"同权"，探针关"残留"，确认门关"落地"。
3. 审计者≠执行者（两个独立 ScriptedLLM 实例）。
4. mock 只演示机制形状，不代表真实模型的抵抗力。

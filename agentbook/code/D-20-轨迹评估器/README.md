## 预期输出

## 观察什么（对应 18.4–18.6）
1. **评轨迹不只评终答**：T2 终答没毛病但越权转账，只看终答会放行。
2. 规则层拦"可枚举的坏"，Judge 层拦"不可枚举的差"——分工不是冗余。
3. pass 率钉进 CI，低于基线即红＝agent 的回归测试。
4. mock 的 judge 脚本只演示接口形状；生产 Judge 须与被评模型异源。

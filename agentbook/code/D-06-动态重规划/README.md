# D-06　外部中断与动态重规划

对应书中：**第 5 章 5.4／5.10.2**。演示触发源三（外部中断）与"结论外存"如何救场。

## 一句话

任务执行到一半注入用户追加需求；对照组忽略中断（尾部漏答），实验组触发重规划——
重规划请求携带**计划版本号＋已完成结论（从 findings.json 读）＋中断证据**。
随后模拟一次上下文压缩：原始观察丢弃，结论自文件恢复——这就是 5.4 说的"重建边界"。

## 命令矩阵

| 命令 | 演示点 | 实测形状（mock） |
| --- | --- | --- |
| `--mock` | 中断→重规划 v1→v2 | replan_count=1；旧计划已完成段保留，未完成段被替换 |
| `--mock --no-replan` | 对照组：中断被忽略 | 尾部答复覆盖检查="漏答（符合预期）" |
| `--mock --compact-at 2` | 压缩时机×结论外存放回 | 压缩后历史仅剩 system＋任务＋findings 摘要 |
| `--mock --max-replans 0` | 反模式二防线（第四把闸） | 打印"重规划次数已达上限→出口 C 降级收尾" |

## 运行产物

`findings.json`（步骤→一句话结论，每步即时落盘）、`plan_v*.json`（外化判据命中时写）、
`telemetry.jsonl`（replan/compact 事件流——视角盒①指纹③的数据源）。

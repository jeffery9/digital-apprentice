# D-15 多模态三管线对比（第 13 章）

**验证日期**：2026-10-15｜**验证环境**：Python 3.11，Linux，`--mock` 离线模式

## 运行
```bash
python pipelines.py --mock
```

## 预期输出
一张三行对照表：A OCR→文本 2/3（成本 1）、B 视觉直读 3/3（成本 4）、C 混合滑动 3/3（成本 5），并标注 A 的错字段"甲方"。

## 观察什么（对应 13.4）
1. **静默字损**：OCR 把"司"读成"可"，不报错、不可见——分离管线的根病。
2. B 全对但每页烧图像 token；C 只为可疑字段升级复核。
3. 落点是工程问题不是站队问题：由每类文档的置信度分布决定。
4. mock 只演示机制形状，不代表任何真实 OCR/VLM 的准确率。

## 最低可跑供应商组合
仅需 Python ≥3.11 标准库。真实模式接任意 OpenAI 兼容 VLM：设 `LLM_ENDPOINT`/`LLM_MODEL`/`LLM_API_KEY`。

# D-17 屏幕动作循环与失效注入（第 14 章）

**验证日期**：2026-10-15｜**验证环境**：Python 3.11，Linux，`--mock` 离线模式

## 运行
```bash
python replay.py --mock                    # 基线两步任务
python replay.py --mock --inject drift     # 注入元素漂移（页面改版坐标过期）
python replay.py --mock --inject popup     # 注入弹窗劫持
```

## 预期输出
基线全断言通过；drift/popup 注入下第二步被当场拦截（✗），并打印逐步轨迹回放与成功与否对照。

## 观察什么（对应 14.5/14.7）
1. **像素点击不可验证**，必须落到状态断言＋坐标断言；否则漂移/劫持静默通过。
2. 轨迹日志是取证与回归测试的原料——没有它 GUI agent 无法上线。
3. mock 的假操作系统只演示验证环的形状，不含任何真实 UI 识别能力。

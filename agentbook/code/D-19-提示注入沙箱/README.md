## 观察什么（对应 17.6–17.9）
1. 攻击面是**工具返回值/检索文档**这类"观察回流"，不只是用户输入。
2. 三层防御是乘法不是加法：串联后端到端落地率趋零。
3. 双通道的合法接口只有结构化摘要——raw 文本永不进规划通道。
4. 确认门默认拒绝（fail-closed）：无人在场＝不执行。
5. mock 只演示机制形状。

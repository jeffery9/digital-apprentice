# D-18 后台长时程：检查点续跑与幂等重试（第 15 章）

**验证日期**：2026-10-15｜**验证环境**：Python 3.11，Linux，`--mock` 离线模式

## 运行（三段剧本按顺序跑）
```bash
python longrun.py --mock --crash-at 2   # 第 3 步提交后崩溃（退出码 42）
python longrun.py --mock --resume       # 从检查点续跑
python longrun.py --mock                # 全新跑完
```

## 预期输出
崩溃剧本 exit=42；续跑剧本跳过已完成步骤、总外部写恰为 5（无重复副作用）。

## 观察什么（对应 15.4/15.6）
1. **提交顺序**（先副作用后检查点）决定"至少一次+幂等"还是"至多一次+丢数据"。
2. 幂等键＝step_id：重放不二次写入——长跑 agent 的财务安全线。
3. 心跳停止后必须由看门狗超时判死，禁止静默悬挂。
4. mock 全程确定性，无网络无 sleep。

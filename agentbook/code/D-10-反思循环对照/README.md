# D-10 反思循环对照

对应书稿第 9 章（反思与自我改进）。三条实验臂在同一任务集上对照：**直出** / **纯自评反思** / **外部验证器反思**。演示"评估器决定反思上限"的机制形状。

## 运行

```bash
python3 run.py --mock        # 全程离线，零第三方依赖，无需 API key
```

## 结构

| 部件 | 书中对应 | 说明 |
| --- | --- | --- |
| `TASKS` 缺陷注入 | 9.2 | format（可见）/ factual（幻觉，自检不可见）/ verbosity（判官偏爱） |
| `verifier_external` | 9.4 | 可行动差异报告的替身（schema/检索核对） |
| `critic_self` | 9.2 | 同源启发式＝证人兼任法官：看不见 factual、偏爱冗长 |
| `revise(external=False)` | 9.3 | 震荡修订＋灌水——收益衰减的脚本形态 |

## 实测要点（书 9.8 引用，2026-10-14）

ext 臂 78.3% 成功、幻觉清零、平均 1.0 轮且 token（175）低于自评臂（212）；self 臂仅 21.7%→35.0% 且幻觉全漏——三臂形状即本章三论点。

## 接真模型路线

- `generate/critic_self/revise` → llm.py 的同一模型三连调用；`verifier_external` → 真实规则/schema/执行验证。
- 换用你的评测集重测斜率——本 demo 交付对照实验的结构，不交付结论数值（铁律三）。
